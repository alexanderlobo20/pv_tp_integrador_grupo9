## Descripción del Proyecto
Aplicación web desarrollada en React que permite la gestión de clientes mediante el consumo de una API externa, incorporando autenticación de administradores, control de acceso por roles, persistencia de sesión, navegación dinámica y operaciones CRUD sobre los datos de clientes.
